# Smart (KAEOSRISANG) Warehouse

ระบบควบคุมคลังสินค้าของ **แก้วศรีสังข์ เซอร์วิส**

- จัดการพนักงาน (ชื่อ-สกุล, เลขบัตรประชาชน 13 หลักพร้อมตรวจเลขถูกต้อง, วันเกิด, เบอร์โทร, ธนาคาร/เลขบัญชี, สถานะ, สาขา, ตำแหน่ง) — เลขบัตรและเลขบัญชีแสดงแบบปิดบางหลัก กดรูปตาเพื่อดูเต็ม
- จัดการสาขา
- จัดการสินค้า 3 ประเภท (วัสดุและอุปกรณ์ / น้ำยาทำความสะอาด / อุปกรณ์การเกษตร) พร้อมรูปภาพ ราคา จำนวนคงเหลือ แจ้งเตือนใกล้หมด รับเข้า/ปรับยอด และประวัติสต็อก
- รับส่งสินค้า: สร้าง/แก้ไขใบส่ง เปลี่ยนจำนวน สาขา สถานะ (ร่าง → กำลังจัดส่ง → ส่งแล้ว) บันทึก PDF แชร์ LINE และ **ตัดสต็อกอัตโนมัติเมื่อยืนยันส่งแล้ว** (ยกเลิกการยืนยันได้ ระบบคืนสต็อกให้)
- สรุปปริมาณและมูลค่าสินค้าที่จ่ายไปแต่ละสาขา (PDF / CSV)
- วิเคราะห์แนวโน้มการใช้สินค้าของแต่ละสาขา พยากรณ์เดือนนี้ และแนะนำสินค้าที่ควรรับเข้าเพิ่ม
- ผู้ใช้ 2 ระดับ: **แอดมิน** (ทำได้ทุกอย่าง) และ **พนักงานสาขา** (ดูใบส่ง/รายงานเฉพาะสาขาตัวเอง และกดยืนยันรับสินค้า)

เทคโนโลยี: หน้าเว็บ HTML/CSS/JavaScript ล้วน (ไม่ต้อง build) · ฐานข้อมูล Supabase · โค้ดเก็บบน GitHub · เปิดใช้งานผ่าน Vercel (หรือ GitHub Pages)

---

## ขั้นตอนติดตั้ง

### 1. สร้างฐานข้อมูล Supabase

1. ไปที่ <https://supabase.com> → สมัคร/เข้าสู่ระบบ → **New project**
   - ตั้งชื่อ เช่น `kaeosrisang-warehouse`
   - Region เลือก **Southeast Asia (Singapore)**
   - ตั้งรหัสผ่านฐานข้อมูลและจดเก็บไว้
2. เมื่อสร้างเสร็จ ไปที่เมนู **SQL Editor** → **New query**
3. เปิดไฟล์ `supabase/schema.sql` คัดลอกทั้งหมดไปวาง แล้วกด **Run** (รันซ้ำได้ ข้อมูลไม่หาย)
4. ไปที่ **Project Settings → API** คัดลอก 2 ค่า
   - **Project URL** เช่น `https://abcd1234.supabase.co`
   - **anon public** key
   > ⚠️ ห้ามใช้ `service_role` key ในหน้าเว็บเด็ดขาด

### 2. ใส่ค่าการเชื่อมต่อ

แก้ไฟล์ `js/config.js`

```js
export const SUPABASE_URL = 'https://abcd1234.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```

ใส่ที่อยู่และเบอร์โทรบริษัทใน `COMPANY` ได้ด้วย (จะแสดงบนหัวใบส่งสินค้า PDF)

> anon key เปิดเผยในหน้าเว็บได้ตามปกติ เพราะข้อมูลถูกป้องกันด้วย Row Level Security ในฐานข้อมูล: ผู้ที่ยังไม่ได้รับอนุมัติจะไม่เห็นข้อมูลใดๆ และข้อมูลพนักงานเห็นได้เฉพาะแอดมิน

### 3. เปิดใช้งานผ่าน Vercel

1. ไปที่ <https://vercel.com> → เข้าสู่ระบบด้วยบัญชี GitHub
2. **Add New → Project** → เลือก repo นี้ → **Import**
3. Framework Preset เลือก **Other** ไม่ต้องตั้ง Build Command → กด **Deploy**
4. จะได้ลิงก์ เช่น `https://kaeosrisang-warehouse.vercel.app`
5. ทุกครั้งที่แก้โค้ดบน GitHub, Vercel จะอัปเดตเว็บให้อัตโนมัติ

(ทางเลือก) **GitHub Pages**: repo → Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save

### 4. ตั้งค่าการยืนยันอีเมลใน Supabase

Supabase → **Authentication → URL Configuration**
- **Site URL**: ใส่ลิงก์เว็บจาก Vercel
- **Redirect URLs**: เพิ่มลิงก์เดียวกัน (และลิงก์ GitHub Pages ถ้าใช้)

### 5. สร้างบัญชีแอดมินคนแรก

1. Supabase → **Authentication → Users → Add user → Create new user**
   ใส่อีเมลและรหัสผ่าน ติ๊ก **Auto Confirm User** → Create user
2. Supabase → SQL Editor รันคำสั่ง (เปลี่ยนอีเมลและชื่อผู้ใช้ตามต้องการ)
   ```sql
   update public.profiles
      set role = 'admin', username = 'ชื่อผู้ใช้', full_name = 'ชื่อ-สกุล'
    where email = 'อีเมลที่ใส่ในขั้นที่ 1';
   ```
3. เปิดเว็บ เข้าสู่ระบบด้วย **ชื่อผู้ใช้** และรหัสผ่าน แล้วกด **เปลี่ยนรหัสผ่าน** (เมนูซ้ายล่าง) เป็นรหัสที่คาดเดายาก

> โปรเจกต์ที่ติดตั้งก่อนมีระบบชื่อผู้ใช้ ให้รันไฟล์ `supabase/002_username_login.sql` เพิ่ม 1 ครั้ง

### 6. เพิ่มพนักงานสาขาเข้าระบบ

ให้พนักงานกด **สมัครใช้งาน** (ตั้งชื่อผู้ใช้เอง) → แอดมินไปที่เมนู **ผู้ใช้ระบบ** → เปลี่ยนสิทธิ์เป็น "พนักงานสาขา" และเลือกสาขา (แก้ชื่อผู้ใช้ หรือลบผู้ใช้ได้ที่หน้านี้)

## ลำดับการใช้งานแนะนำ

1. **สาขา** → เพิ่มสาขาทั้งหมด
2. **สินค้าและสต็อก** → เพิ่มสินค้า ใส่รูป ราคา จำนวนเริ่มต้น และจุดแจ้งเตือนใกล้หมด
3. **พนักงาน** → บันทึกข้อมูลพนักงาน
4. **รับส่งสินค้า** → สร้างใบส่ง → เริ่มจัดส่ง → เมื่อของถึงสาขา กด **ยืนยันส่งแล้ว** (สต็อกถูกตัดทันที)
   - ส่งให้สาขาทาง LINE: กด **แชร์ LINE** (บนมือถือแนบไฟล์ PDF ได้เลย บนคอมพิวเตอร์ระบบจะเปิดหน้าแชร์ LINE พร้อมข้อความ และดาวน์โหลด PDF ให้แนบ)
   - ส่งผิด: แอดมินกด **ยกเลิกการยืนยัน** ระบบคืนสต็อก แล้วแก้ไขใบส่งได้
5. **สรุปการจ่ายสินค้า** และ **แนวโน้มการใช้สินค้า** → ดูรายงาน (ต้องมีข้อมูลอย่างน้อย 2–3 เดือนจึงจะเห็นแนวโน้มชัด)

## การป้องกันข้อมูลที่ระบบทำไว้

- สต็อกเปลี่ยนได้ผ่าน 3 ทางเท่านั้น: ยืนยันส่งแล้ว, ยกเลิกการยืนยัน, รับเข้า/ปรับยอด — ทุกครั้งมีบันทึกในประวัติสต็อก
- ยืนยันส่งไม่ได้ถ้าสต็อกไม่พอ และใบที่ส่งแล้วแก้ไข/ลบไม่ได้จนกว่าจะยกเลิกการยืนยัน
- ข้อมูลพนักงาน (เลขบัตร/บัญชีธนาคาร) อ่านได้เฉพาะแอดมิน ทั้งในหน้าเว็บและที่ฐานข้อมูล

## โครงสร้างไฟล์

```
index.html              หน้าเว็บหลัก
assets/styles.css       หน้าตา
js/config.js            ค่าการเชื่อมต่อ Supabase และข้อมูลบริษัท
js/app.js               ล็อกอิน เมนู เปลี่ยนหน้า
js/store.js             เชื่อมต่อ Supabase
js/ui.js                ตัวช่วยหน้าจอ (ตรวจเลขบัตร, ปิดบางหลัก ฯลฯ)
js/pdf.js               สร้าง PDF และแชร์ LINE
js/charts.js            กราฟและการคำนวณแนวโน้ม
js/pages/*.js           แต่ละหน้า
supabase/schema.sql     ตาราง ฟังก์ชันตัดสต็อก และสิทธิ์การเข้าถึง
vercel.json             ตั้งค่า Vercel
```
